# 慧医数字医疗应用系统前端功能文档

## 1. 项目概述

本项目是一个基于 Vue 3、Vite、Vue Router、Element Plus、ECharts 的数字医疗后台管理系统。前端提供登录、首页仪表盘、医药公司管理、政策管理、必备材料管理、城市信息管理、销售地点管理、药品信息管理、医生管理、用户管理、用户授权、密码管理等后台功能。


## 2. 技术栈

| 类别 | 技术 |
| --- | --- |
| 构建工具 | Vite |
| 前端框架 | Vue 3 |
| 路由 | Vue Router 4 |
| UI 组件库 | Element Plus |
| 图表 | ECharts、vue-echarts |
| HTTP 请求 | Axios |
| 本地状态 | localStorage |

## 3. 全局功能

### 3.1 登录认证

- 登录页路径：`/login`
- 登录表单字段：用户名、密码
- 当前实现：使用模拟登录数据生成 `mock-token`，写入 `localStorage.token`，并写入 `localStorage.user`
- 路由守卫：访问带 `requiresAuth` 的路由时检查 `localStorage.token`
- 退出登录：清除 `token`、`user` 并跳转到 `/login`
- 已封装后端接口：`POST /api/auth/login`、`GET /api/users/me`

### 3.2 主框架与导航

- 主布局路径：`/`
- 左侧菜单：仪表盘、医药公司管理、必备材料管理、城市信息管理、销售地点管理、药品信息管理、医生管理
- 顶部区域：当前页面标题、在线状态、用户头像、用户下拉菜单
- 用户下拉菜单：个人资料、用户列表、用户授权、修改密码、重置密码、退出登录

### 3.3 统一请求规则

- 请求基础路径：`/api`
- 请求超时：10 秒
- Token Header：`Authorization: Bearer <token>`
- 成功响应约定：`code === 200`
- 失败处理：根据响应 `code` 或 HTTP 状态码弹出错误提示

## 5. 模块功能

### 5.1 仪表盘

- 展示当前登录用户欢迎语和当前日期
- 展示统计指标：合作公司、必备材料、城市信息、销售地点、药品种类、注册医生
- 统计卡片支持点击跳转到对应业务列表页
- 医生职级柱状图：按 `doctor.title` 统计
- 医院科室饼图：按 `doctor.department` 统计
- 最新政策表格：按 `effectiveDate` 倒序取前 5 条
- 当前数据来源：`localStorage.companies`、`materials`、`cities`、`locations`、`medicines`、`doctors`、`policies`

### 5.2 医药公司管理

- 公司列表支持按公司名称、城市筛选
- 表格字段：ID、公司名称、联系人、联系电话、城市、地址
- 操作：新增、编辑、删除、分页
- 新增/编辑表单字段：公司名称、联系人、联系电话、城市、地址
- 城市候选项当前写死为北京、上海、广州、深圳
- 当前数据来源：`localStorage.companies`

### 5.3 政策管理

- 政策列表支持按政策名称、适用公司筛选
- 表格字段：ID、政策名称、适用公司、生效日期、过期日期
- 操作：新增、编辑、删除、分页
- 新增/编辑表单字段：政策名称、适用公司、开始/生效日期、过期日期、政策内容
- 新增政策时会根据 `companyId` 映射生成 `companyName`
- 当前数据来源：`localStorage.policies`

### 5.4 必备材料管理

- 材料列表支持按材料名称、材料类型筛选
- 表格字段：ID、材料名称、材料类型、描述
- 操作：新增、编辑、删除、分页
- 新增/编辑表单字段：材料名称、材料类型、描述
- 当前数据来源：`localStorage.materials`

### 5.5 城市信息管理

- 城市列表支持城市名称查询
- 表格字段：ID、城市名称、所属省份、城市代码
- 操作：新增、编辑、删除、分页
- 新增/编辑表单字段：城市名称、所属省份、城市代码
- 当前数据来源：`localStorage.cities`

### 5.6 销售地点管理

- 地点列表支持按地点名称、城市筛选
- 表格字段：ID、地点名称、城市、地址、联系人、联系电话
- 操作：新增、编辑、删除、分页
- 新增/编辑表单字段：地点名称、城市、地址、联系人、联系电话
- 地图展示页当前为占位组件，展示固定地点卡片，尚未接入真实地图 SDK
- 当前数据来源：`localStorage.locations`，城市下拉来自 `localStorage.cities` 或默认城市

### 5.7 药品信息管理

- 药品列表支持按药品名称、药品类型筛选
- 表格字段：ID、药品名称、药品类型、规格、价格、生产厂家
- 操作：新增、编辑、删除、分页
- 新增/编辑表单字段：药品名称、药品类型、规格、价格、生产厂家
- 当前数据来源：`localStorage.medicines`

### 5.8 医生管理

- 医生列表支持按医生姓名、科室筛选
- 表格字段：ID、医生姓名、科室、职称、联系电话、邮箱
- 操作：新增、编辑、删除、分页
- 新增/编辑表单字段：医生姓名、科室、职称、联系电话、邮箱
- 邮箱字段有前端格式校验
- 当前数据来源：`localStorage.doctors`

### 5.9 用户管理

- 用户列表支持按用户名、角色筛选
- 表格字段：ID、用户名、角色、创建时间
- 操作：新增入口、编辑入口、删除、分页
- 注意：路由中当前没有 `/user/add` 和 `/user/edit/:id`，但列表页存在跳转入口，后续需要补页面或调整入口
- 当前数据来源：`localStorage.users`

### 5.10 用户授权

- 支持按用户名查询授权用户
- 表格字段：ID、用户名、权限
- 提供授权操作入口
- 后端应提供用户权限读取与保存能力

### 5.11 密码管理

- 修改密码表单字段：原密码、新密码、确认新密码
- 前端校验：必填、确认密码与新密码一致
- 重置密码页面支持按用户名查询用户列表，并提供重置操作入口
- 当前页面逻辑偏模拟，后端应补充真实修改密码和重置密码接口

## 6. 当前代码审查结论

- 前端路由和页面模块基本完整，覆盖主要后台管理功能。
- `src/api` 已经预留用户、公司、政策、材料、城市、地点、药品、医生的 REST 接口封装。
- 实际页面尚未普遍调用 `src/api`，多数增删改查直接读写 `localStorage`。
- 登录页没有调用 `login()` API，而是使用模拟 token。
- `PolicyList.vue` 中新增/编辑跳转使用了 `/policy/add`、`/policy/edit/:id`，但实际路由是 `/company/policy/add`、`/company/policy/edit/:id`，后续需要修正。
- `UserList.vue` 中新增/编辑跳转到 `/user/add`、`/user/edit/:id`，但路由未定义对应页面。
- 部分源码中文出现编码异常，建议统一以 UTF-8 保存。
- 销售地点地图页目前只是占位展示，未接真实地图服务、经纬度字段和地理编码。
